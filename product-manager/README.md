# PanelsPro - Laravel Product Manager

A minimal, fast, and beautiful product management application built with Laravel 11.

## Features
* Clean minimal UI (Black & White Theme)
* Admin Dashboard for CRUD operations
* Product image uploads
* Active/Inactive product toggles
* Secure authentication
* SQLite database (No setup required)

## Installation

1. Clone the repository
2. Run `composer install`
3. Run `php artisan migrate --seed`
4. Run `php artisan storage:link`
5. Run `php artisan serve`

Admin Login: `admin@admin.com` / `password`
